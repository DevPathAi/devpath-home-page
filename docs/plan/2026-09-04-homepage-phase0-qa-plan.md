- Start the guest diagnostic without authentication after arriving with no UTM and with a valid UTM tuple.

- Open every product screenshot at phone, tablet and desktop widths; confirm it is legible, not duplicated by an internal mockup headline, and does not expose personal or credential data.

- Navigate header, mobile menu, skip link, CTA, note links and footer with keyboard only.
- In AdSense `review` mode, confirm publisher wiring and `ads.txt` exist and no slot is displayed.
- In `approved_manual` mode, confirm one responsive slot on note detail only and no advertising runtime on every excluded route.
- Exercise Home preview promotion, production canary and rollback with a known prior deployment.
- Exercise legacy landing redirect, observation, runtime disable, credential rejection and repository archive gates in their required order.

## Edge Cases

- Missing, partial, duplicated, overlength or unapproved UTM values must not block the diagnostic and must not be stored.
- Denied or unavailable sessionStorage must not make the page blank or prevent diagnosis.
- Existing unrelated query values and URL fragments must survive identifier cleanup.
- Repeated CTA instrumentation must not duplicate `journeyId` or UTM keys.
- A required Home build input, privacy page, routing file or `ads.txt` missing must fail the build with the exact path.
- A screenshot whose bytes do not match its evidence manifest must fail before preview deployment.
- Broken YouTube, font CDN, AdSense or analytics requests must leave core content and CTA usable.
- One transient Home probe failure must not roll back; two consecutive Home-owned failures must.
- App or third-party failure during Home canary must alert without rolling back a healthy Home deployment.
- Redirects must preserve path/query without chains or loops for all known paths and a deterministic random sample.
- Incomplete export count/hash must prevent redirect, disable and credential revocation.
- Any old Function invocation during the 24-hour observation window must prevent runtime disable.
- Failed provider revocation must stop finalization and report the exact blocked provider action.
- AdSense no-fill must keep the article readable and CLS at or below 0.10.
- Performance measurements must use three runs and the median; two absolute-budget failures out of three fail the release.

## Critical Paths

- Existing visitor: Home without UTM emission → production app → guest diagnostic starts successfully.
- New visitor: Home CTA with approved UTM → app captures session attribution → visible URL is clean → `diagnostic_started` uses analytics v2.
- Applicant/reviewer: Home → Before/After evidence → four actual steps → beta access explanation → guest diagnostic.
- Release operator: immutable Home artifact → protected deployment CAS → exact production deployment → 30-minute canary → success evidence.
- Rollback: Home-owned consecutive failure → exact prior Cloudflare deployment restored → marker and core routes verified.
- Legacy retirement: inventory/export verified → single-hop redirects → 24-hour zero invocation → runtime disabled → credentials rejected → repo archived.
- Ad approval: approval evidence bound → approved-manual preview → one note-detail slot → performance/privacy checks → Home-only release → canary.
